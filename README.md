# Webprogramozás 1 – Vaszilij EDC

Háromfős beadandó projekt a Vaszilij EDC weboldal témájára,
a tanári PHP front-controller minta felhasználásával.

## Technológiák
HTML, CSS, JavaScript, PHP és MySQL/MariaDB.

## Helyi indítás
1. A projekt mappája: C:\xampp\htdocs\webprog-beadando
2. XAMPP-ban az Apache és a MySQL elindítása.
3. Első beállításkor a gyakorlat7.sql importálása phpMyAdminban.
4. Megnyitás: http://localhost/webprog-beadando/

## Jelenlegi állapot
- A tanári mintaprojekt helyben működik.
- A mintaadatbázis importálva.
- A belépés mintafelhasználóval ellenőrizve.
